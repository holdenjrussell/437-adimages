# 437 brand assets

Official 437 brand marks and palette card. Source of truth:
`~/studio-kit-config/brand/` on the ops machine; this directory is the
public delivery copy.

## Color tokens

| Token | Hex | Use |
|---|---|---|
| Parchment | `#EFEFE6` | Primary background |
| Stone | `#E8E6E7` | Secondary background / neutral surface |
| Slate | `#000000` | Primary text and dark marks |
| Powder | `#FFFFFF` | Light marks / reverse text |
